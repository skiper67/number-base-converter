# Number Base Converter

Расширение для Visual Studio Code, которое переводит целые числа между двоичной, восьмеричной, десятичной и шестнадцатеричной системами. Выделите `255` в редакторе, выберите перевод **10 → 16** и получите `0xFF`. Результат можно скопировать в буфер обмена или сразу подставить вместо выделения.

## Возможности

- Перевод числа из выделенного текста или из поля ручного ввода.
- Поддержка отрицательных и больших целых чисел. Расчёты выполняются с `BigInt`, поэтому цифры больших целых сохраняются без округления.
- Проверка цифр и префикса для выбранной исходной системы.
- История переводов за сеанс, общее число операций и две диаграммы.

## Как перевести число

1. Выделите число в редакторе или оставьте выделение пустым для ручного ввода.
2. Откройте палитру команд через **Ctrl+Shift+P** и выберите **«Перевод чисел: перевести число»**. При выделенном тексте команда также доступна в контекстном меню.
3. Укажите исходную систему счисления. При ручном вводе введите число после выбора системы.
4. Выберите целевую систему. В уведомлении появится результат и доступные действия.

| Исходное число | Из системы | В систему | Результат |
| --- | ---: | ---: | --- |
| `255` | 10 | 16 | `0xFF` |
| `0b1101` | 2 | 10 | `13` |
| `0755` | 8 | 10 | `493` |
| `-0x1A` | 16 | 2 | `-0b11010` |

Исходная система задаётся явно. Например, `101` в системе 2 означает пять, а в системе 10 — сто один. При вводе можно использовать префиксы `0b`, `0o` и `0x`, соответствующие выбранному основанию. Восьмеричный результат выводится с начальным `0`, как в C и C++.

## Статистика сеанса

Команда **«Перевод чисел: статистика сеанса»** открывает панель с общим количеством переводов, таблицей исходных чисел и результатов и двумя диаграммами:

- **По целевой системе** — сколько раз переводили в каждую из четырёх систем.
- **По направлению** — сколько раз выполняли конкретный перевод, например **10 → 16**.

В историю попадает каждый успешный расчёт, в том числе если пользователь только просмотрел результат. Статистика хранится в памяти текущего сеанса. Команда **«Перевод чисел: сбросить статистику»** очищает историю и начинает новый сеанс.

## Сборка и запуск из исходников

Понадобятся VS Code и Node.js с npm. Откройте в VS Code папку проекта с `package.json`. Команды ниже рассчитаны на PowerShell в Windows.

```powershell
npm.cmd install
npm.cmd run compile
```

Esbuild создаст `dist/extension.js`. Нажмите **F5**, чтобы открыть окно проверки расширения. В нём выполните перевод `255` из системы 10 в систему 16. Ожидаемый результат — `0xFF`. После изменений в исходном `extension.js` повторите сборку перед перезапуском отладки.

<details>
<summary>Настройки сборки в package.json</summary>

В проекте со сборкой `main` указывает на `./dist/extension.js`, а внутри `scripts` есть команда `compile`.

```json
"compile": "esbuild extension.js --bundle --platform=node --external:vscode --outfile=dist/extension.js"
```

Для подключения сборщика к шаблону установите его командой `npm.cmd install --save-dev esbuild` и добавьте указанные настройки. Параметр `--external:vscode` оставляет модуль `vscode` внешним, поскольку его предоставляет редактор.

</details>

## Упаковка в VSIX

В корне проекта выполните команды:

```powershell
npm.cmd install -g @vscode/vsce
npm.cmd run compile
vsce.cmd package --allow-missing-repository --skip-license
```

Первая команда устанавливает упаковщик. При повторной сборке достаточно выполнить две следующие. Для версии `0.0.1` получится файл `number-base-converter-0.0.1.vsix`.

Чтобы установить пакет, в VS Code откройте **Расширения → «…» → «Установить из VSIX…»** и выберите полученный файл. Команды установленного расширения доступны через палитру команд.

## Как устроен проект

| Файл | Назначение |
| --- | --- |
| `extension.js` | Чтение числа, преобразование через `BigInt`, команды редактора и панель статистики |
| `package.json` | Описание расширения, команды и настройки сборки |
| `.vscode/launch.json` | Запуск расширения в отдельном окне через F5 |
| `dist/extension.js` | Результат сборки, который загружает VS Code |

При переводе расширение сначала проверяет строку и получает значение `BigInt`, затем записывает его в целевой системе через `toString(base)`. Для статистики каждый перевод добавляется в массив истории. Панель строит таблицу и диаграммы по этому массиву с помощью HTML и CSS.
